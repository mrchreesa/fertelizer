# WebM8 website analytics

The homepage, Consumer Terms and order-complete page load the WebM8 statistics installer with public site ID `4462fe0c-beef-4ddf-ae26-0253da1ae08c`, registered to Commonwealth Central. On 13 October 2026 the owner confirmed statistics-only use and requested removal of both the pop-up and on-page opt-out controls, including in the shared installer. Statistics now start automatically for a fresh browser. Existing saved declines, including expired declines, Do Not Track and Global Privacy Control remain respected. The installer does not write a new acceptance on the visitor's behalf.

`assets/site-analytics.js` is an exact local copy of the updated canonical shared installer at `/Users/kreeza/Desktop/WebM8/webm8-platform/apps/analytics/public/site-analytics.js`. Its `data-origin` selects the existing WebM8 tracker/collector host. This ensures the local preview and deployment package use the updated installer before the platform is released. Keep the copy aligned with the canonical source when updating it. The former remote installer and its injected UI stylesheet are not loaded by these pages.

`assets/analytics-bridge.js` applies the same saved-choice/browser-signal gate to Vercel analytics. The homepage's custom-event handler also checks this state. Named sections and buy links retain their labels. A buy click or order-complete view does not assert that a payment succeeded. Payment links are unchanged.

The Content Security Policy admits `https://webm8-platform.vercel.app` in script-src and connect-src; it no longer needs that host in style-src. Keep the remaining security policy in place. Deploys come from the `mrchreesa/fertelizer` main branch; the local .vercel metadata refers to an older project and should not be used to select a deployment target.

This is a technical configuration change, not a determination of legal exemption. The [ICO's statistical-purposes guidance](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/what-are-the-exceptions/) still requires clear information and a simple, free means of objecting. The owner was informed of this before the controls were removed. No alternative objection workflow is implemented here.
